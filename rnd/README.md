# Autonomous R&D Workspace

This directory is for governed autonomous research and development only.

## Permitted work

- research and analysis
- historical studies
- diagnostics and observability
- tests and validation tooling
- documentation
- prospective non-production experiments
- shadow-execution architecture and candidates

## Prohibited authority

Autonomous R&D must not:

- modify frozen M006e
- modify canonical M005
- change strategy, risk, or sizing authority
- change the master execution switch
- add broker-order submission capability
- alter accepted manifests, hashes, or evidence
- promote candidates into the accepted trading stack
- self-merge pull requests
- authorize live capital

All material changes remain PR-first and subject to human review.
